    Create frontend/lib/features/election/data/vote_service.dart as a new file.

    Required imports: dart:convert (not needed — GraphQLService handles decode), and
    package:sistema_eleitoral_frontend/core/services/graphql_service.dart. No other imports.

    Define the following types in this order:

    1. A file-level constant: const _kAlreadyVotedMessage = 'Já votou nesta eleição.';
       This is the exact string the backend returns for AlreadyVoted (per Phase 2 plan
       MutationType.scala mapping case Left(AlreadyVoted) => CastVoteErrorPayload("Já votou
       nesta eleição.")).

    2. sealed class CastVoteResult — no fields, no constructor, just sealed.

    3. final class CastVoteSuccess extends CastVoteResult — const constructor with named
       required fields: voteId String, electionId String, votedAt String. Follow the
       CreateElectionSuccess pattern from election_service.dart exactly.

    4. final class CastVoteAlreadyVoted extends CastVoteResult — const constructor with
       no fields: const CastVoteAlreadyVoted().

    5. final class CastVoteFailure extends CastVoteResult — const constructor with
       required field: message String.

    6. class VoteCountItem — NOT sealed, NOT final. Fields: candidateId String,
       candidateName String, count int (all required). Const constructor with named
       parameters. Add a factory VoteCountItem.fromJson(Map<String, dynamic> json)
       that reads: candidateId from json['candidateId'] as String, candidateName from
       json['candidateName'] as String, count from (json['count'] as num).toInt()
       — use "as num" then ".toInt()" for web-safe int casting (Pitfall 3 from research).

    7. class VoteService — constructor VoteService(this._graphql) where _graphql is
       final GraphQLService _graphql. Follow the ElectionService constructor pattern exactly.

       Method castVote({required String electionId, required String candidateId})
       returns Future<CastVoteResult>. The mutation string (raw string r'''...''') is:
         mutation CastVote($electionId: String!, $candidateId: String!) {
           castVote(electionId: $electionId, candidateId: $candidateId) {
             ... on CastVoteSuccess { voteId electionId votedAt }
             ... on CastVoteError { message }
           }
         }
       Call _graphql.execute(query: mutation, variables: {'electionId': electionId,
       'candidateId': candidateId}). Extract result['data']?['castVote'] as
       Map<String, dynamic>?. If null, return CastVoteFailure(message: 'Resposta
       inválida do servidor.'). If data.containsKey('voteId'), return CastVoteSuccess
       with the three fields. Otherwise read message as data['message'] as String? ??
       'Erro desconhecido.'. If message == _kAlreadyVotedMessage return
       CastVoteAlreadyVoted(). Otherwise return CastVoteFailure(message: message).
       Wrap the entire _graphql.execute call in try/catch Exception; on exception
       return CastVoteFailure(message: e.toString()).

       Method getVoteResults(String electionId) returns Future<List<VoteCountItem>>.
       The query string (raw string r'''...''') is:
         query ElectionResults($electionId: String!) {
           electionResults(electionId: $electionId) {
             candidateId candidateName count
           }
         }
       Call _graphql.execute(query: query, variables: {'electionId': electionId}).
       Extract result['data']?['electionResults'] as List<dynamic>?. If null, throw
       Exception('Resposta inválida do servidor.'). Return
       list.cast<Map<String, dynamic>>().map(VoteCountItem.fromJson).toList().
       Do NOT catch exceptions in getVoteResults — let them propagate to FutureBuilder
       for error display.

    IMPORTANT — do NOT pass voterId from the Flutter client. The mutation only takes
    electionId and candidateId; the server extracts voterId from the JWT. Adding
    voterId would cause a GraphQL "Unknown argument" error.
